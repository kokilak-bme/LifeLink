## Problem Statement

Blood and organ matching is often fragmented and reactive, causing delays during critical medical emergencies.

## Solution Overview

**LifeLink** is a healthcare platform that enables faster and more reliable matching by:

* Checking blood-bank inventory first
* Ranking donors using a transparent trust score
* Providing improved organ waitlist visibility
